# Gerenciador de Tarefas 📝

Aplicativo web de gerenciamento de tarefas desenvolvido como projeto acadêmico para o curso de Análise e Desenvolvimento de Sistemas da **Faculdade CDL**.

## 🚀 Tecnologias
* **HTML5**
* **CSS3** (Estilização em tons pastéis)
* **JavaScript (Vanilla JS)**
* **LocalStorage** (Persistência de dados)

## ✨ Funcionalidades
* Adicionar, editar e excluir tarefas.
* Definição de nível de prioridade (Baixa, Média e Alta).
* Inclusão de data de conclusão.
* Controle de limite de até 10 tarefas ativas.
* Alertas visuais e validações.
